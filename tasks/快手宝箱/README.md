# 快手宝箱自动领取

循环做这件事：点左上角金币宝箱 → 弹窗点「领取奖励」 → 看倒计时走完 → 再点 → 下一轮。

## 跑法

```bash
python tasks\快手宝箱\ks_bot.py        # 一直跑，Ctrl+C 停
python tasks\快手宝箱\ks_bot.py 10     # 跑 10 轮自动退出
```

也可以在 `gui.py` 里选「④ 快手宝箱自动领取」，填轮数后点开始。

## 前提

- 手机停在快手的视频/广告页（不要停在其他 App）
- WDA 已就绪（先跑 `python core\wda_up.py`）

## 它怎么判断状态

用 pymobiledevice3 的无障碍通道读屏幕上所有文字（约 4.8 秒一次），匹配这几种：

| 屏幕上看到 | 含义 | 动作 |
|---|---|---|
| `NNs后可领取NNNN金币` | 还在计时 | 不动，等 |
| `已成功领取NNNN金币` | 可以领了 | 点宝箱 (107,78) |
| 弹窗里有 `领取奖励` | 弹窗已出 | 点 (207,514) |

判定不到（界面卡在其他广告落地页）时会上滑换一条，失败多次会停 10 秒再试。

## 坐标

| 目标 | 坐标 |
|---|---|
| 左上角金币宝箱 | (107, 78) |
| 弹窗「领取奖励」 | (207, 514) |
| 上滑换视频 | (207,720) → (207,260) |

坐标是 iPhone 11 的 414×896 点坐标系。换机型要重新量：`python core\quick.py shot data\shots\a.png`，
截出来的 828×1792 像素图，像素 ÷ 2 就是坐标。
