# 大麦抢票

> 执行脚本不在这个文件夹里：连点/流水线引擎是通用能力，放在 `tasks/通用/fasttap.py`，
> 本文件夹只放抢票流程说明。
盲点连点器：不读界面，只按坐标高频点击。适合抢票这类"按钮位置固定、必须比别人快点几下"的场景。

## 跑法

```bash
# 单点连击：对着 (207,800) 每 120ms 点一次，点 40 次
python tasks\大麦抢票\fasttap.py 207 800 --delay 120 --rounds 40

# 定时开抢：进程提前起来挂着，到 12:00:00 那一刻才开始点
python tasks\大麦抢票\fasttap.py 207 800 --delay 120 --rounds 40 --at 12:00:00

# 多段流水线：点完一个位置 → 等页面加载 → 点下一个位置
python tasks\大麦抢票\fasttap.py --script "207,800,120,20; wait:1500; 207,700,120,10"
```

`gui.py` 里对应「② 快速连点（单点）」和「③ 连点流水线（多步）」。

## 参数

| 参数 | 说明 |
|---|---|
| `x y` | 屏幕坐标点（iPhone 11 是 414×896） |
| `--delay` | 两次点击间隔，毫秒。120 是实测比较稳的值 |
| `--rounds` | 点多少次，0 表示一直点 |
| `--at` | `HH:MM:SS`，到点才开始。已经过的时间会按明天算 |
| `--script` | 多段脚本：`x,y,间隔ms,次数`，分号分隔；`wait:1500` 表示停 1.5 秒 |

## 完整的抢票流程（建议）

抢票不是一步，是一串固定动作。推荐用 `--script` 一次串起来：

```
阶段 0  你在手机上手动做好：登录、预约场次、预填观演人、停在演出详情页
阶段 1  程序定时：开售前 3 秒进程就起来挂着，到点瞬间开始点「立即购买」
阶段 2  页面跳转后点票档 → 点「确定」→ 点「提交订单」
阶段 3  没跳转就返回重来，弹窗（已售罄/排队中）就关掉继续
阶段 4  停在提交订单页，交给你手动付款
```

对应脚本大概是：

```
--script "207,800,120,15; wait:1800; 207,620,120,3; wait:600; 300,780,120,3; wait:800; 207,820,120,5"
```

里面的坐标必须按你自己手机的实际页面量，别直接用这串。

## 重要提醒

- **单次点击约 2.2 秒**（当前 WDA 默认设置）。这是最大瓶颈：如果目标很热门，这个速度基本抢不到开售的第一批。
  降到 200-400ms 的办法是关掉 WDA 的 `waitForQuiescence`，还没实测。
- 抢开售的票打不过脚本党，**捡回流票**（别人释放的）才是这个工具真正有用的地方：挂着循环点，有人退票就接上。
- 验证码必须你自己点，程序不会也不该过验证码。
- 只用你自己已登录的账号，不做多账号代抢。
